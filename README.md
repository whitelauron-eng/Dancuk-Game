# Jejak Argumen — Petualangan Bahasa Indonesia
Media asesmen interaktif teks argumentasi untuk kelas III SD.

## Publikasi ke GitHub Pages
1. Buat repositori baru di GitHub.
2. Unggah semua file dari ZIP ini ke root repositori.
3. Buka Settings → Pages.
4. Pilih Deploy from a branch, branch `main`, folder `/ (root)`, lalu Save.
5. Buka alamat GitHub Pages yang muncul.

## Fitur
- 20 pilihan ganda + 5 isian singkat.
- Skor 4 poin per soal, maksimal 100.
- Umpan balik, pembahasan, suara pembaca teks (Text-to-Speech browser).
- Tampilan responsif untuk HP, tablet, dan komputer.

## Catatan
Isian diperiksa dengan daftar variasi jawaban yang diterima. Guru perlu meninjau jawaban alternatif yang benar secara makna. Aspek praktik berbicara (intonasi, volume, gestur), kefasihan membaca, dan kemampuan menulis teks utuh perlu dilengkapi observasi/unjuk kerja guru.

Sumber pengembangan: *Bahasa Indonesia: Kawan Seiring untuk SD/MI Kelas III (Edisi Revisi)*, Bab 2 “Yuk, Berpendapat!” (Kementerian Pendidikan Dasar dan Menengah, 2025).
